# Decision Scorecard

Every candidate solution is scored independently before promotion.

| Criterion | Weight |
|---|---:|
| ColorOS correctness | 25 |
| Functional correctness | 20 |
| Runtime reliability | 15 |
| Security | 15 |
| Performance/resource use | 10 |
| Android compatibility | 5 |
| Maintainability | 5 |
| License/provenance compliance | 5 |

A candidate cannot become PREFERRED without reproducible evidence and mandatory security/license checks. A high score never overrides a failed mandatory gate.
