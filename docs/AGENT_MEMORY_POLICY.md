# Agent Memory and Promotion Policy

Agents may contribute findings, fixes, test evidence and research. Shared memory is evidence-first: every promoted fact must point to a reproducible artifact, test result or authoritative source.

Agents must distinguish facts from hypotheses. Conflicting findings remain visible until resolved. Repeatedly successful repairs can be promoted to `PROVEN` and then `PREFERRED`; promotion must not erase prior evidence.

The Director periodically consolidates duplicate findings, retires stale guidance, and keeps rollback knowledge available.
